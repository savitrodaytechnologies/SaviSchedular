⚡ Quick Start — 3 Steps

1

Admin UI se API Key Generate Karo

SaviSchedular Admin → API Keys section → "New API Key" → Key copy karo (sirf ek baar dikhega)

2

Har Request mein Header Lagao

X-SaviSchedular-Key: your_api_key_here
3

API Call Karo

Neeche diye endpoints use karo — schedule create, update, trigger, delete sab possible hai

Endpoints

POST Create / Update Schedule
GET Check Schedule Status
POST Manual Trigger
DELETE Delete Schedule

Responses

🟢 200 OK — Success
🔴 401 Unauthorized — Invalid Key
🔴 403 Forbidden — Product Access Denied
🔴 400 Bad Request — Missing Fields
🔴 404 Not Found — Schedule nahi mili
POST Create / Update Schedule
/api/external/schedule Upsert — schedule hai to update, nahi to create
🔐
Header required: X-SaviSchedular-Key: YOUR_API_KEY
Admin UI → API Keys se generate karo
Request Body (JSON)
FieldTypeRequired?Description
productCodestring Required Product ka code jaise SAVISCHOOLS, 10XVIRAL
jobTypeCodestring Required WHATSAPP_ABSENT, FEE_REMINDER etc.
externalIdstring Required Aapka SchoolId ya ClientId (e.g. "1093")
clientNamestring Optional School ka naam (first time register ke liye)
scheduledHourint (0–23) Required Job kitne baje chale — 24hr format
scheduledMinuteint (0–59) Optional Default: 0
payloadJsonstring (JSON) Optional Extra POST body params: {"companyId":"1"}
isActivebool Optional Default: true
timeZonestring Optional Default: India Standard Time
Example Request
HTTP 
POST https://scheduler.savischools.com/api/external/schedule
Content-Type: application/json
X-SaviSchedular-Key: abc123def456...

{
  "productCode":     "SAVISCHOOLS",
  "jobTypeCode":     "WHATSAPP_ABSENT",
  "externalId":      "1093",
  "clientName":      "Delhi Public School",
  "scheduledHour":   10,
  "scheduledMinute": 0,
  "payloadJson":     "{\"companyId\":\"1\",\"branchId\":\"5\"}",
  "isActive":        true,
  "timeZone":        "India Standard Time"
}
C# Example (SaviSchools se call karo)
C# 
// NuGet: Newtonsoft.Json
var client = new HttpClient();
client.DefaultRequestHeaders.Add("X-SaviSchedular-Key", "your_key_here");

var body = JsonConvert.SerializeObject(new {
    productCode     = "SAVISCHOOLS",
    jobTypeCode     = "WHATSAPP_ABSENT",
    externalId      = schoolId.ToString(),
    clientName      = schoolName,
    scheduledHour   = 10,
    scheduledMinute = 0,
    payloadJson     = $"\"{\\\"companyId\\\":\\\"{companyId}\\\"}\",
    isActive        = true
});

var response = await client.PostAsync(
    "https://scheduler.savischools.com/api/external/schedule",
    new StringContent(body, Encoding.UTF8, "application/json")
);
